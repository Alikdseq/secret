# SEO

Пакет SEO Research Agent. Шаблон: `templates/seo-research.md`.

Сюда кладётся `seo-research.md` и сырой `wordstat-raw.json`.

Роль не обязательный этап конвейера. Папка пустая, пока CEO или Office Manager не поставили исследование спроса.

Статьи и тексты страниц здесь не появляются. Рядом с Wordstat-отчётом SERP Research Agent кладёт `serp-research.md` и `serp-raw.json`. Черновые URL из Wordstat он не переписывает.
